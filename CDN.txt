1. CDN (Content Delivery Network) – FAANG Level Design
🔹 What is a CDN?

A CDN is a globally distributed system of servers that delivers content (images, videos, JS, HTML) closer to users to reduce latency.

Think:
Cloudflare, Akamai, Amazon CloudFront

🔹 High-Level Architecture
User → DNS → Edge Server → Cache → Origin Server
Components:
DNS Routing
Geo-based routing (user hits nearest edge)
Uses Anycast IP
Edge Servers (PoPs)
Cache static content
Located globally
Origin Server
Source of truth (S3 / backend server)
Cache Layer
In-memory (Redis) + disk cache
🔹 Request Flow
User requests image.jpg
DNS routes to nearest edge
Edge:
If cache hit → return
If miss → fetch from origin → cache → return

FAANG-Level Optimizations
1. Cache Strategies
TTL-based expiry
LRU eviction
Cache invalidation via API
2. Consistent Hashing
Distribute content across servers
Avoid massive reshuffling
3. Compression
Gzip / Brotli
4. Protocol Optimizations
HTTP/2, HTTP/3 (QUIC)
5. Edge Computing
Run logic at edge (auth, A/B testing)

Scaling
Add more PoPs (horizontal scaling)
Use load balancing inside PoPs
Multi-region replication

Trade-offs
Freshness vs latency
Cost vs performance
Consistency vs availability (CAP)
